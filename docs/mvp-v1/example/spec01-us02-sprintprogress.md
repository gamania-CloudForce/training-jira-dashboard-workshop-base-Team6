# spec01-us02-sprintprogress.md

## User Story
作為專案成員，我希望能在儀表板上清楚看到自己任務的依賴關係與協作夥伴進度，以便更有效協作與規劃。

---

### Acceptance Criteria

#### AC01: 正常流程 - 成功檢視任務依賴關係
場景：專案成員想了解自己任務的依賴關係，並確認協作夥伴的進度。
Given 使用者已登入儀表板
And 儀表板已成功串接 Jira 看板資料，且任務之間已建立「阻擋」或「被阻擋」的關聯性
When 使用者點擊自己負責的任一任務
Then 儀表板應以視覺化的方式（例如：箭頭或線條）突顯出此任務所依賴的任務
And 儀表板應同時標示出依賴於此任務的其他任務
And 每個相關任務應清晰顯示其負責人與當前狀態

#### AC02: 邊界條件 - 任務無依賴關係
場景：專案成員負責的任務沒有任何依賴關係。
Given 使用者已登入儀表板
And 任務資料中該任務無「阻擋」或「被阻擋」的關聯性
When 使用者點擊該任務
Then 儀表板應明確顯示「此任務無依賴關係」提示
And 不顯示任何依賴視覺化標記

#### AC03: 異常情況 - Jira 資料串接失敗
場景：儀表板無法取得任務依賴資料。
Given 使用者已登入儀表板
And 因網路或 API 問題導致無法取得 Jira 任務依賴資料
When 使用者嘗試檢視任務依賴關係
Then 儀表板應顯示「資料載入失敗，請稍後再試」的友善提示
And 提供重新整理或重試的選項
